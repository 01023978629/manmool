# 견적서·계약서 비교 가이드

## 범위

- `data/site.json`에 `interior-quote-contract-comparison` 안내 글 1건 추가.
- 게시일 2026-09-09, 공식 자료 확인일 2026-09-08.
- 기존 38개 글과 현장 앱 자료·사진 원본을 보존한다.
- 실제 시공 후기나 만물 작성 계약서가 아닌 교육용 가이드로 구분한다.
- 가설·목공·도장·시트지·타일·전기·소방의 세부 내역 비교 질문과 부가세·지급·하자 접수를 짧은 문단으로 안내한다.
- 타일 부분 보수와 전체 철거·시공 비교는 가상 설명 예시이며, 실제 두 번째 업체 견적을 확인한 것이 아니다.
- 특정 업체 평가, 실제 가격 공개, 법률 판단·지급 비율·보증 기간 단정은 제외한다.

## 공개 이미지와 AI 편집 지시 요약

- 모드: 내장 이미지 생성·편집 도구, 기존 사진 편집. CLI 사용 없음.
- 최종 파일: `assets/insights/interior-quote-details-ai-redacted.png`.
- 최종 요청에 따라 세부 내역이 보이도록 표 부분만 발췌하고, 금액·세액·비고 내용은 가린다. 회사·고객 식별정보, 주소·연락처·계좌·직인·날짜가 있는 상·하단은 제외한다.
- 원본과 문자·서식 픽셀이 동일하다는 주장은 하지 않는다. AI 편집 표 이미지 1개를 사용하며, 원본·제출용 문서가 아닌 설명용 편집본임을 표시한다.
- 앞서 세부 내역을 모두 가렸던 후보는 비공개 폴더에 보관하고 공개에서 제외했다. 원본 사진은 변경하지 않았다.
- 최종 편집 프롬프트: [quote-details-image-prompt.md](quote-details-image-prompt.md).
- 공개 표시: **AI 편집 설명용 이미지 — 세부 내역 표시, 식별정보·금액 비공개. 계약서 원본이나 제출용 문서가 아닙니다.**

## 분류와 생성

- 정보 글을 날짜가 새롭다는 이유만으로 `최신 현장`에 표시하지 않는다.
- 대표 현장은 작업 요약이 있는 실제 사례 중 최신 글을 사용한다. 그 외 글은 최신순 일반 카드에 배치한다.
- 정본에서 `scripts/prerender-posts.py`로 게시 페이지·목록·RSS를 생성한다.
- 정보 글은 누수 실제 사례 색인에 넣지 않는다.
- 사이트맵에 신규 주소를 추가하고 블로그 목록 갱신일을 반영한다. 변경 없는 누수 페이지 날짜는 올리지 않는다.

## 검증 기준

신규 안내 글 테스트는 기존 정본 보존, AI 고지, 개인정보·금액·과장 표현,
공개 이미지 범위, EXIF/GPS 메타데이터, 공식 출처, 인테리어 상담 연결,
목록·RSS·사이트맵 발견 가능성을 확인한다. 합성 변이로 차단 동작도 검증한다.
이미지 픽셀의 가림 상태는 자동 검사로 보증하지 않고 별도로 시각 검토한다.

배포 성공 여부는 이 문서만으로 판단하지 않는다. 해당 PR과 Pages 실행 결과,
공개 페이지·이미지 응답을 별도로 확인해야 한다.
