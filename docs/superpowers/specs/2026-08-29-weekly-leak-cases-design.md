## 사실성 원칙

- 원장에 적힌 작업명과 사진에서 직접 보이는 상태만 쓴다.
- 원장에 없는 누수 원인, 탐지 방법, 통수시험, 작업 시간, 보험 처리, 전유부·공용부 판정은 만들지 않는다.
- 완료 결과를 과장하지 않고 `작업 후 촬영 상태`로 표현한다.
- 실제 현장 기록형 문체로 쓰고 각 소제목의 내용은 2~4줄 분량으로 짧게 구성한다.

## 개인정보와 사진 처리

- 공개 글·제목·대체텍스트·캡션·파일명에는 원장 프로젝트명과 동·호수를 넣지 않는다.
- 지도와 상세 주소를 넣지 않는다.
- 인물, 문패, 외부 전망, 세대 식별 맥락이 보이는 사진은 사용하지 않는다.
- 선택된 15장만 사용하고 원본은 수정·이동·삭제하지 않는다.
- 모든 공개 사진은 EXIF를 완전히 제거하고 JPEG로 새로 인코딩한다.
- 긴 변은 최대 1600px, JPEG 품질 82, progressive/optimized 저장, 파일당 500KB 이하로 맞춘다.
