# 옥내급수관 개량 지원사업 시공 자격 서면질의

## 받는 곳

대전광역시 상수도사업본부 관할 지역사업소 급수 담당. 국민신문고에서 대전광역시를 처리기관으로 지정하거나 대전시 온라인 민원창구로 제출합니다.

## 붙여넣을 질의 본문

만물인테리어(사업자등록번호 895-48-01132)는 노후 옥내급수관 개량 지원사업 참여 가능 범위를 확인하고자 합니다. 아래 각 문항에 예/아니오와 적용 근거를 함께 답변해 주십시오.

1. 배관기능사 자격을 보유한 개인사업자가 지원대상 주택의 옥내급수관 교체 공사를 직접 시공할 수 있습니까?
2. 위 공사 시 「건설산업기본법」상 상·하수도설비공사업 등록이 반드시 필요합니까?
3. 공사 금액 또는 작업 범위에 따라 전문건설업 등록 의무가 달라집니까?
4. 지원금 지급을 위해 시공업체가 사전에 등록·협약·교육을 받아야 합니까?
5. 필요한 자격·등록·제출서류 목록을 받을 수 있습니까?
