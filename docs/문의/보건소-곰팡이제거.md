# 누수 수반 곰팡이 제거·방균 도포 소독업 해당 여부 질의

## 받는 곳

공사 장소 관할 보건소 감염병관리·위생 담당. 국민신문고 또는 보건소 전자민원으로 제출합니다.

## 붙여넣을 질의 본문

만물인테리어는 누수 원인 수리 뒤 젖은 마감재를 철거하고, 국소 곰팡이를 물리적으로 제거한 뒤 시판 방균제를 도포하는 부수 작업을 검토 중입니다. 감염병 방역·법정 소독을 표방하지 않습니다. 아래 문항에 예/아니오와 근거를 답변해 주십시오.

1. 위와 같은 국소 작업을 반복적으로 유상 제공하면 감염병예방법상 소독업 신고 대상입니까?
2. “곰팡이 제거”, “방균 도포”, “누수 후 위생 복구” 중 사용하면 안 되는 서비스 명칭이 있습니까?
3. 살균·소독 효과를 광고하지 않고 물리적 제거와 마감 복구만 하면 신고 대상에서 제외됩니까?
4. 사용하는 약제가 생활화학제품 안전기준 적합 제품이면 별도 인허가 없이 사용할 수 있습니까?
5. 신고 대상이라면 시설·장비·인력 및 교육 요건 목록을 받을 수 있습니까?
