# 전체 사례 목록의 분야별 표시

- 요청: 전체에서도 누수·배관, 인테리어, 정보를 구분해서 표시.
- 정적 목록 생성기에 분야별 section·제목·건수를 추가했다. JavaScript가 꺼져 있어도 세 그룹과 글 링크가 남는다.
- 기존 카드 한 벌을 유지하며 검색·필터·정렬 시 해당 그룹의 격자 안에서만 이동한다. 빈 그룹은 숨기고 건수는 검색 결과에 맞게 갱신한다. 최신 실제 사례 대표 카드는 해당 분야 안에 유지한다.
- 전체의 날짜 정렬은 분야 안에서 적용한다. 개별 분야 필터, 검색어, 뒤로가기 상태 복원 및 개인정보 비전송 동작은 유지했다.
- 정적 목록 복구용 동적 렌더도 같은 그룹 구조를 사용한다. 기존 정적 분류와 어긋났던 ‘가이드’ 분류를 정보로 맞췄다.
- 공개 원고 52건과 사진·현장 데이터는 변경하지 않았다. 현재 표시 건수는 누수·배관 22건, 인테리어 12건, 정보 18건이며 향후 정본에 맞춰 자동 계산한다.
- 목록 검색 회귀, JS 비활성화, 동적 복구, 구역별 건수·혼입·중복, 모바일 화면 및 브랜드 화면 검사로 확인한다.
