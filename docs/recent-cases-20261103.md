- `date`는 사진(EXIF 촬영일 11/3 10:41~15:11)으로 확인한 작업일이다. 원본 34장 중 전·중·후가 드러나는 9장만 공개한다.
- 현장명은 10/21 견적서('송촌 선비 1단지 / 외부미장')와 10/7 공개 사례와 같은 단지다. 단지 안 어느 구간인지(동)는 적지 않는다.
- 표면이 떨어진 원인, 부착 시험 결과, 작업 시간, 공사 금액, 발주처(누수나라)·작업자 이름은 적지 않는다.
  "방수 효과" 같은 성능 주장도 쓰지 않았다 — 사진에 보이는 미장 보수 범위로만 적었다.

- 공개용 사진 9장은 방향 보정·긴 변 1600px·EXIF/GPS/XMP 제거 사본(≤480KB)이다. 모바일용 480w·960w 18장을 만들었다.
  기존 사진의 축소본은 다시 만들지 않았다(`build-image-variants.py`가 새로 쓴 기존 축소본은 되돌렸다).
- 이 글이 가장 최근 실제 사례가 되어 `blog.html` 대표 사례 칸과 `leak.html` #cases 첫 카드로 간다. 카드 수 핀 34→35

- sitemap: 새 글(`lastmod` 2026-11-03), `blog.html`·`leak.html`의 `lastmod` 2026-11-03.
- 기존 76건 전체 객체·순서와 업체 정보·시안은 `recent-cases-20261103` 검사가 해시로 고정한다(origin/main `2e0c484`와 대조 일치).
