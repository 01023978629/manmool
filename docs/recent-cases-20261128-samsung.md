원고는 사례 작성 폴더의 비공개 초안(`published:false`, 11/28 고침·새로 씀)이고 이 PR 에서 `published` 만 `true` 로 바꿨다 —
제목·소개문·장소·요약 카드·본문·사진 설명·상담 안내·관련 글은 한 글자도 고치지 않았다(새 검사가 글 객체 전체를 글마다 `entryHash` 로 고정).
현장 앱 데이터, 당근·네이버 지도·카카오맵 게시 글은 이 PR 에 없다. 이 PR 은 검사 통과 뒤 대표의 병합(공개) 승인을 기다린다.
