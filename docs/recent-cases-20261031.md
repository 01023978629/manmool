- `date`는 사진으로 확인한 작업일이다(여러 날이면 마지막 날). 같은 10월 공개분(삼호·옥천·방충망)과 같은 기준이다.
  예미지 도막 날짜는 자료마다 달라(공사내역서 10/2, 사진 10/6) 본문에 날짜를 적지 않았다.
- 용전동 현장의 단지명은 대표 확인 전이라 제목·요약·지도 검색(`place`)에서 뺐다. 확인되면 `place`를 더한다.
- 우수관 현장은 사진에 보이는 하부 연결부·배수구 범위로만 적었다. 관 본체 교체 여부는 단정하지 않는다.
- 선비마을 1단지 보일러 배관(10/7)은 9/29 공개 사례(선비마을아파트 보일러 배관)와 별도의 작업 기록이다.
- 동·호수, 고객 이름·연락처, 얼굴·차량번호, 위치 메타데이터를 공개하지 않는다. 확인되지 않은 누수 원인,
  압력·통수시험 결과, 작업 시간, 공사 금액은 적지 않는다.
- 공개용 사진 78장은 방향 보정·긴 변 1600px 이하·EXIF/GPS/XMP 제거 사본이다. 모바일용 480w·960w 156장을 만들었다.
- `leak.html` 사례 카드 10장을 날짜 위치에 추가했다(23→33). `scripts/ensure-promo-pages.mjs` 카드 수 핀도 같이 올렸다.
- 관련 글은 같은 누수 분야만 생성기가 받으므로, 다른 분야를 가리키던 3건(산호·예미지·범지기)을 누수 사례로 바꿨다.
- sitemap: 새 글 10건(`lastmod` = 작업일), `blog.html`·`leak.html`의 `lastmod`는 최신 공개 글 날짜 2026-10-29.
- 기존 65개 원고 전체 객체·순서와 업체 정보·시안은 `recent-cases-20261031` 검사가 해시로 고정한다
  (origin/main `53a6bef`와 대조 일치). 기존 개별 검사 6개의 핀은 새 기준으로 다시 고정하고 날짜 주석을 남겼다.
