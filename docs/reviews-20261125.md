# 고객 후기 — 이름 가림·화면 escape·메일 전용·누수 페이지 후기 칸 (2026-11-25, M1)

브랜치 `claude/reviews-stats-area-20261125`(origin/main `965956c` 에서). 실제 후기는 아직 0건이고, 이 작업도 후기를 지어내지 않는다.
대문·누수 페이지의 후기 칸은 지금처럼 **0건이면 숨겨진 채** 나간다.

## 바뀐 것

| 무엇 | 어디 | 내용 |
|---|---|---|
| (a) 이름 가림 | `scripts/new-review.mjs` | `--name` 을 성+○ 로 바꾼다: 홍길동 → 홍○○, 김민 → 김○, "홍길동 고객님" → "홍○○ 고객님". 이미 가린 이름(김○○)·"고객" 은 그대로. 한글 이름 꼴이 아닌 값(닉네임·영문)은 가릴 수 없어 거부한다 — 성을 알면 성+○○, 모르면 "고객". 같은 실명이 현장·본문에 있으면 거기서도 가린다. |
| (a) 막기 | `scripts/ensure-review-intake.mjs` | `site.json reviews` 의 `name` 이 가린 꼴(`isMaskedDisplayName`, 규칙은 new-review.mjs 한 곳)이 아니면 실패. |
| 분야 | `scripts/new-review.mjs` `--service leak\|interior` (필수) | 누수 페이지 후기 칸이 `leak` 만 고른다. 검사도 두 값만 허용. |
| 줄끝 | `appendReview` | site.json 의 원래 줄끝(CRLF/LF)을 지켜 다시 쓴다(윈도우 작업본이 통째로 LF 로 바뀌지 않게). |
| (b) escape | `js/main.js renderReviews` | 글·이름·현장을 `escapeContent` 로만 넣는다. 별점은 1~5 정수일 때만 그린다(문자열이 `aria-label` 속성으로 새지 않게). |
| (c) 메일 전용 | `js/lead-transport.js` `inboxAccepts` | `type:'후기'` 는 문의 접수함(Apps Script)에 보내지 않는다 — 접수함(`LeadInboxPure.gs`)에 후기 종류가 없어 전화가 든 후기가 '인테리어' 상담 줄로 섞였다. 메일(Web3Forms·n8n)만 간다. 재전송도 같다. `backendConfigured(config, payload)` 가 종류를 받아 접수함만 켜진 설정에서는 후기를 '보낼 길 없음'으로 판정한다(문자·복사 대안이 나온다). **Apps Script 쪽은 고치거나 재배포하지 않았다.** |
| (c) 안내 | `js/review.js`, `review.html`, `privacy.html #privacy-review-items` | 경로 판정에 종류를 넘긴다. 이름 칸·공개 동의·완료 안내에 "성만 보이게 가림", 처리방침에 "후기는 접수함에 기록하지 않고 메일로만" 을 적었다(사실 그대로). |
| (d) 누수 후기 칸 | `leak.html #leakReviews`(자주 묻는 질문 앞) · `scripts/prerender-posts.py write_leak_reviews` | `<!-- leak-reviews:start … end -->` 사이를 생성기가 `site.json reviews` 중 `service:"leak"` 으로 다시 그린다. 0건이면 `hidden`. 누수 페이지는 500KB 넘는 site.json 을 받지 않으므로(누수 접수 색인과 같은 이유) 정적으로 박는다. CSS: `css/leak-theme.css`·`css/service-leak.css`, 폰 44px 링크: `css/service-design.css`. |
| CI | `.github/workflows/deploy-pages.yml` | 생성물 비교에 `leak.html` 추가, `tests/review-render.test.cjs` 추가. |

후기를 공개할 때 순서(대표 승인 뒤):

```bash
node scripts/new-review.mjs --rating 5 --name "홍길동" --service leak --space "대전 ○○아파트 · 욕실 누수" --text "…"   # 이름은 홍○○ 로 들어간다
python3 scripts/prerender-posts.py        # 누수 후기면 leak.html 후기 칸이 열린다
node scripts/ensure-review-intake.mjs && node scripts/ensure-promo-pages.mjs
```

## 시험

- `tests/review-render.test.cjs`(새, 브라우저 없이 `js/main.js` 를 `node:vm` 으로 읽음) 3건: 0건 숨김, 글·이름·현장 escape, 별점 거름.
- `tests/lead-inbox-transport.test.cjs` 새 3건: 후기는 메일만·접수함만 켜지면 '길 없음'·메일 실패 때 접수함으로 새지 않음·재전송.
- `tests/test_prerender_posts.py` `LeakReviewTests` 2건: 0건 숨김, 누수만·escape·별점 거름.
- `scripts/ensure-review-intake.mjs` 확인 63건(이전 44건).
- 시험의 이름·전화·현장은 모두 가상(가○○, 010-0000-0000 꼴, 가상구)이다.

## 이 PC 에서 못 돌린 것

playwright 가 없어 브라우저 e2e(`tests/review-intake.e2e.cjs` 등)는 돌리지 못했다. review-intake e2e 는 접수함을 끈 설정으로 돌아가므로
이번 변경(접수함 제외)의 영향 범위 밖이고, 성공 화면 확인 문구("대표가 확인한 뒤")도 그대로다.

## 대표 확인 대기

- 접수함(Apps Script)에 '후기' 종류를 따로 두고 싶으면 서버(`apps-script-lead-inbox/`) 수정·재배포가 먼저다. 그 전까지 후기는 메일로만 온다.
- 닉네임 후기는 공개할 때 "고객" 으로 올린다(가릴 수 없어서). 다르게 하고 싶으면 알려 주세요.
