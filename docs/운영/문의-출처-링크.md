# 문의가 어디서 왔는지 세기 — 링크 끝 꼬리표(UTM) 안내 · 대표님용

> 구글 애널리틱스 같은 **가입·계정 없이**, 홈페이지 상담 신청이 당근에서 왔는지, 네이버 블로그에서 왔는지,
> 카카오 채널에서 왔는지 세는 방법입니다. 링크 끝에 꼬리표를 붙여 두면, 그 링크로 들어온 손님이 상담을 신청할 때
> 꼬리표가 문의와 함께 기록됩니다. (2026-11-25부터 인테리어 상담 폼도 누수 상담 폼처럼 기록합니다.)

꼬리표 글자 규칙: 영문·숫자·한글·밑줄(_)·하이픈(-)만, 80자 이내. 띄어쓰기 대신 하이픈을 쓰세요.
**전화번호처럼 보이는 숫자는 기록하지 않고 버립니다**(개인정보가 섞이지 않게).

## 2. 어디서 세나요

- **문의 접수함**(`lead-inbox.html`) — 문의를 누르면 아래쪽에 `유입 페이지`·`진입점`·`UTM` 칸이 있습니다.
  예: UTM `daangn / profile`. 진입점은 어느 폼으로 신청했는지입니다 —
  `index-inquiry-submit`(인테리어 상담), `leak-inquiry-submit`(누수 상담), `office-pilot-submit`(관리사무소 파일럿).
- **접수함 구글 시트** — `문의` 시트의 `utm` 열에 필터를 걸면 채널별 개수가 나옵니다.
- **메일**(Web3Forms) — 본문 아래쪽에 `유입 페이지: /leak.html`, `신청 진입점: …`, `UTM Source: daangn` 줄이 붙습니다.

## 3. 알아 둘 점 — 세지 못하는 것

- 링크로 들어와서 **그 화면에서 바로** 신청해야 기록됩니다. 다른 메뉴로 옮겨 가서 신청하면 꼬리표가 빠집니다
  (손님 브라우저에 따로 저장하지 않습니다).
- **전화 버튼·카카오 버튼으로 바로 연락한 손님은 세지 못합니다.** 누른 횟수를 기록하려면 접수함 서버(Apps Script)를 고쳐
  다시 배포해야 해서 이번에는 하지 않았습니다.
- **방문자 수·페이지 조회 수는 세지 않습니다.** 그건 구글 애널리틱스(GA4)·네이버 애널리틱스처럼 계정이 필요한 도구가 있어야 하고,
  이번에는 만들지 않았습니다. 필요하시면 말씀해 주세요 — 계정 만들기는 대표님이 하셔야 합니다.
- 꼬리표는 개인정보가 아니지만, 개인정보처리방침에 "어느 경로로 문의가 왔는지 기록한다"고 적어 두었습니다(`privacy.html#privacy-lead-source`).
