## A. 문의 접수함 켜기 (약 30분, 한 번만)

홈페이지 문의가 구글 시트에 이력으로 남고 `lead-inbox.html` 에서 승인·보류·거절을 기록하는 기능입니다. 코드는 배포됐지만 **대표님 구글 계정으로 서버를 한 번 올려야 켜집니다.** 그 전까지는 지금과 완전히 같습니다(메일만).

순서는 `apps-script-lead-inbox/README.md` 그대로입니다.

- ☐ 1. 접수함 전용 구글 스프레드시트 **새로** 만들기 (다른 시트 재사용 금지)
- ☐ 2. script.google.com 새 프로젝트 → `Code.gs`, `LeadInboxPure.gs`, `appsscript.json` 넣기
- ☐ 3. 스크립트 속성 5개 등록 (`LEAD_INBOX_ENABLED`=1, `LEAD_INBOX_SHEET_ID`, `LEAD_INBOX_SESSION_SECRET`, `LEAD_INBOX_LOGIN_PEPPER`, `LEAD_INBOX_ADMIN_CODE`)
  - 관리 비밀번호(`LEAD_INBOX_ADMIN_CODE`)는 8자 이상·공백 없이, **대표님만 아는 값**. 카톡·메모·문서 어디에도 적지 마세요.
  - 선택: `LEAD_INBOX_NOTIFY_TO` 에 메일 주소를 넣으면 새 문의가 올 때마다 그 주소로 알림 메일이 갑니다(Web3Forms 메일이 실패해도 이 메일은 옵니다).
- ☐ 4. 편집기에서 `leadInboxSetupSheets_` 한 번 실행 (권한 승인)
- ☐ 5. 배포 → 새 배포 → 웹 앱 · 실행 사용자 "나" · 액세스 "모든 사용자"
- ☐ 6. 나온 `https://script.google.com/macros/s/…/exec` 주소를 **저에게 전달** → 제가 `data/config.json` 에 넣고 켠 뒤 시험 문의로 끝까지 확인
- ☐ 7. 첫 로그인 뒤 시험 문의는 화면에서 **거절**(사유: 시험)로 정리
