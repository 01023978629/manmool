# 부여 부영아파트 베란다 방수 사례

## 근거와 범위

- 확인 범위: 한국 시간 2026-09-07부터 09-08까지 현장 앱에 올라온 사진과 현장 기록.
- 부여 부영아파트 사진 10장을 확인하고 서로 다른 장면 6장을 선정했다.
- 별도의 카페 견적 예시 사진 1장은 시공 현장 사례가 아니므로 제외했다.
- 공개 내용: 초기 바닥·배수구, 1차 몰탈 방수 후 바닥, 2차 도막 도포 단계.
- 공개하지 않는 주장: 누수 원인 확정, 정확한 소요 시간, 담수시험 통과, 최종 타일 마감 완료.
- 공개 위치는 단지명까지다. 동·호수, 고객 정보, 원본 경로, Drive 식별자는 포함하지 않는다.

## 사진 처리

- 사용자 승인에 따라 도막 사진 2장의 창밖 차량 번호판만 일반 픽셀 편집으로 가렸다.
- AI 생성·시공 부위 수정·사진 합성은 하지 않았다.
- 가림 전후의 픽셀 차이가 지정된 가림 영역 밖에 없음을 JPEG 저장 전에 검사했다.
- 6장 모두 방향 보정, 비율 유지 축소(1350×1800), JPEG 저장과 메타데이터 제거를 적용했다.
- 480px·960px 파생 이미지 12장은 같은 공개용 사진에서 만들었다.
- 원본 사진과 현장 앱 데이터는 수정하지 않았다. 원본 해시 대조·출처 기록은 로컬 비공개 자료에만 보관한다.
- 자동 검사는 번호판 픽셀의 가독성을 판단하지 못하므로 두 가림 사진을 별도 시각 검토했다.

## 게시 연결

정본은 `data/site.json`의 `buyeo-buyeong-balcony-waterproofing`이다.
비공개 초안 작성 후 정본에 추가하고 기존 생성기로 정적 글·블로그 목록·RSS·누수 사례 색인을 재생성했다.
누수 페이지 최신 카드와 sitemap도 연결했다. 기존 37개 원고 객체와 나머지 사이트 데이터가 동일함을 비교했다.
기존 글의 관련 글 카드만 생성기에 의해 새 사례로 갱신된다. RSS는 기존 정책대로 최신 30건이다.
누수 페이지의 기존 10개 카드는 보존했으며 새 1건에 맞춰 카드 수 검사도 정확히 11개로 고정했다.

## 검증

- 원고·사진·분류·게시 연결 `ensure-*` 원본 검사: 22/22 통과.
- 신설 사례 검사: 6/6 통과. 사진 누락·중복·EXIF·좌표·정본 누락·사진 순서·카드 누락 변이 검출 포함.
- 비공개 초안 생성기: 14건 통과. 정적 글 생성기 Python 검사: 5건 통과.
- 공개 허용목록 산출물: 502개 파일, source/output 일치 검사 통과.
- 390px 및 1280px 로컬 산출물 화면: 본문 6장 표시, 가로 넘침 없음, 최신 카드 클릭 연결, 페이지 오류 없음.
- 사례·검색 12건, 서비스 화면 23건, 브랜드 화면 13건: 브라우저 회귀 48/48 통과. 로컬 GET만 허용했으며 운영 접수·계정은 호출하지 않았다.
- 최종 원고 변경 뒤 신설 사례 검사 6건 재통과, 생성물 41개 재생성 멱등성 및 원본·공개용 사진 6장씩 해시 재확인 완료.
- GitHub 배포 완료 여부는 PR 검사와 main 병합 뒤 Pages 실행 및 공개 URL 응답으로 별도 확인한다.
