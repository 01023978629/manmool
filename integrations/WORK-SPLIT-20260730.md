4. 기존 계약 DB 백업을 수정하지 않고 읽기 전용으로 분석해 이관 스크립트를 만든다.
5. 현장 PWA가 새 Apps Script API를 쓰도록 변경하고 테스트·운영 문서를 작성한다.
6. 실제 Solapi 발송은 끝까지 OFF로 유지한다.

## 대표님이 할 일 — 계정·명의·현장 확인

1. 클로드에 위 명령문을 실행시킨다.
2. Google Apps Script가 준비되면 대표님 Google 계정에서 권한을 승인하고 웹앱으로 배포한다.
3. 배포 결과의 `/exec` 주소를 Codex에 알려준다. 관리자 토큰·API Secret은 채팅에 보내지 않고 Script Properties에 직접 넣는다.
4. 아버지 명의 카카오 비즈니스 채널 인증과 템플릿 승인은 아버지 계정으로 진행한다.
5. 네이버·구글 사이트 소유확인 코드를 발급받아 Codex에 전달한다.
6. 폰에서 현장 PWA를 홈 화면에 추가하고 본인 번호로 최종 테스트한다.
