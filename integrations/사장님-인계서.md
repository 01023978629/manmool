## A-3. 관리자 화면에 로그인이 안 되실 때 — 토큰 재발급

### [ ] 관리자 토큰(ADMIN_TOKEN) 새로 발급
**저도 Fly도 그 값을 다시 보여줄 수 없습니다.** 꺼내 볼 수 없게 저장되는 값이라
남은 방법은 새로 정하는 것 하나뿐입니다. **계약·서명 기록은 지워지지 않습니다** —
데이터는 `contract_data` 볼륨(`/data/contract.db`)에 따로 있고, 토큰만 바뀝니다.

```bash
openssl rand -hex 16
#   ↑ 출력된 32자리를 먼저 메모 (이게 새 비밀번호)

fly secrets set ADMIN_TOKEN=메모한값 -a manmool-contract
```
두 번째 명령을 넣으면 서버가 한 번 재시작하고, 그 뒤 새 토큰으로 로그인됩니다.
메모는 사진으로 남기지 마시고 비밀번호 관리 앱이나 수첩에 적어 두세요.
(운영에서는 24자 미만 토큰을 서버가 거부합니다 — `openssl rand -hex 16`이 32자라 안전합니다.)

- 결정적으로 **브라우저에서 못 씁니다.** 서버용 시크릿 키를 요구하고 CORS로 막혀 있어, 현장 앱이 직접 부를 수 없습니다. 쓰려면 계약 서버에 통로를 하나 더 만들어야 합니다.
- → **카카오(B-2)로 충분합니다.** 카카오는 브라우저에서 바로 되고, 무료 한도가 명확합니다.
