
이름 `FLY_API_TOKEN`, 값 붙여넣기.

**지금 서버가 옛 버전인지 확인하는 법(10초):** `/admin` → 설정에 **「대표 완료통지 수신번호」** 칸이 보이면 최신, 안 보이면 옛 버전.

### [ ] B-2. 카카오 JavaScript 키 — 현장 사진 위치 정밀도
현장 사진의 GPS를 **도로명+건물번호·건물명·지번**까지 바꿔줍니다. 지금 쓰는 무료 OpenStreetMap은 한국 건물 이름이 자주 비어 있습니다.

1. **developers.kakao.com** → 내 애플리케이션 → 애플리케이션 추가하기
2. 앱 키 화면에서 **JavaScript 키** 복사 — **REST 키 아님**
3. 앱 설정 → 플랫폼 → **Web 플랫폼 등록** → `https://01023978629.github.io`
   ⚠️ **3번을 빼먹으면 키를 넣어도 작동하지 않습니다.** 가장 많이 놓치는 단계입니다.
4. 제품 설정 → 카카오맵 **활성화 ON**
5. 현장 앱 **☁️ 설정 → 📍 현장 사진 위치 정밀도(카카오)** 에 붙여넣기

**왜 JavaScript 키인가** — REST 키는 도메인 제한이 없어 브라우저 앱에 넣으면 누가 가져다 자기 서비스에 씁니다. JS 키는 등록한 주소에서만 작동합니다.
**요금** — 좌표→주소 변환 **하루 10만 건 무료**, 초과분 건당 0.5원. 사장님 사용량이면 근처도 못 갑니다.
**키 보관** — 사장님 폰에만 저장되고 저장소·백업 파일에 들어가지 않습니다(검사로 못박아 뒀습니다).

### 네이버 지도 API (Reverse Geocoding) — ❌ 지금은 권하지 않음

- 무료 이용량에 대해 **자료가 서로 엇갈립니다.** 무료 한도가 있다는 안내와, 2025년 7월 1일자로 무료 혜택이 끝났다는 안내가 함께 나옵니다. **공식 요금 페이지는 이 환경에서 열리지 않아 제가 확인하지 못했습니다.**
- 결정적으로 **브라우저에서 못 씁니다.** 서버용 시크릿 키를 요구하고 CORS로 막혀 있어, 현장 앱이 직접 부를 수 없습니다. 쓰려면 계약 서버에 통로를 하나 더 만들어야 합니다.
- → **카카오(B-2)로 충분합니다.** 카카오는 브라우저에서 바로 되고, 무료 한도가 명확합니다.

무료(하루 25,000회)이지만 **Client Secret이 필요해 서버 없이는 못 씁니다.** 나중에 계약 서버가 살아난 뒤 다시 볼 만합니다.
